# models/

Trọng số mô hình KHÔNG được đưa vào Git (`.gitignore` chặn). Thư mục này chỉ chứa README và (khi cần) `manifest.json`.

`manifest.json` sẽ ghi, cho mỗi mô hình dùng khi suy luận: tên, nguồn công khai, revision cố định, ngày phát hành gốc (phải trước 26/10/2026), giấy phép, số tham số (tổng ≤ 15B, MoE tính đủ) và SHA-256. Hiện chưa chọn mô hình nào.
